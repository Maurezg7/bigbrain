## Un idioma que se lee como se escribe

El alemán es lengua oficial en Alemania, Austria, Suiza y Liechtenstein, y la lengua materna más hablada de la Unión Europea. Su ortografía es **muy regular**: conocidas las reglas, se puede leer en voz alta casi cualquier palabra.

Dos rasgos visibles:

- Todos los **sustantivos** se escriben con mayúscula inicial: *das Haus* (la casa), *die Zeit* (el tiempo).
- Se forman **palabras compuestas** largas uniendo otras: *Hand* (mano) + *Schuh* (zapato) = *Handschuh* (guante).

## El alfabeto

Tiene las 26 letras latinas más cuatro propias:

| Letra | Nombre | Suena |
|---|---|---|
| ä | a con diéresis (*Umlaut*) | como una «e» abierta |
| ö | o con diéresis | labios de «o» diciendo «e» |
| ü | u con diéresis | labios de «u» diciendo «i» |
| ß | *Eszett* | «s» sorda, como en «casa» |

La *ß* solo aparece después de vocal larga o diptongo: *Straße* (calle), *heiß* (caliente). Después de vocal corta se escribe *ss*: *Fluss* (río). En Suiza no se usa.

## Vocales

Cada vocal puede ser **larga** o **corta**, y la diferencia cambia el significado.

| Es larga cuando | Ejemplos |
|---|---|
| va duplicada | *Boot* (bote), *See* (lago) |
| la sigue una h | *fahren* (conducir), *Uhr* (reloj) |
| es «ie» | *Liebe* (amor), *viel* (mucho) |
| la sigue una sola consonante | *Tag* (día), *gut* (bueno) |

| Es corta cuando | Ejemplos |
|---|---|
| la sigue una consonante doble | *Mann* (hombre), *kommen* (venir) |
| la siguen dos o más consonantes | *Kind* (niño), *Stadt* (ciudad) |

Pares que solo se distinguen por la duración: *Staat* (Estado) y *Stadt* (ciudad); *Miete* (alquiler) y *Mitte* (centro).

## Diptongos

| Se escribe | Suena | Ejemplos |
|---|---|---|
| ei, ai | «ai» | *nein* (no), *Mai* (mayo) |
| ie | «i» larga | *sie* (ella), *Bier* (cerveza) |
| eu, äu | «oi» | *heute* (hoy), *Häuser* (casas) |
| au | «au» | *Haus* (casa) |

> [!WARNING]
> **ei** suena «ai» y **ie** suena «i». Confundirlos es el error más típico del principiante: *Wein* («vain») es vino; *Wien* («viin») es Viena.

## Consonantes

| Se escribe | Suena | Ejemplos |
|---|---|---|
| w | como la «v» inglesa | *Wasser* (agua) |
| v | «f» (en palabras alemanas) | *Vater* (padre), *viel* |
| z | «ts» | *Zeit* (tiempo), *zehn* (diez) |
| j | «y» | *ja* (sí), *Jahr* (año) |
| s antes de vocal | «s» sonora, con vibración | *Sonne* (sol), *lesen* (leer) |
| sch | «sh» | *Schule* (escuela) |
| sp, st al inicio | «shp», «sht» | *sprechen* (hablar), *Straße* |
| ch después de a, o, u, au | «j» española | *Buch* (libro), *acht* (ocho) |
| ch después de e, i, ä, ö, ü o consonante | «j» suave, cerca de una «sh» | *ich* (yo), *Milch* (leche) |
| chs | «ks» | *sechs* (seis) |
| h al inicio | aspirada suave | *Haus* |
| h después de vocal | muda; alarga la vocal | *gehen* (ir) |
| qu | «kv» | *Qualität* |
| tsch | «ch» | *Deutsch* (alemán) |
| pf | «pf», los dos sonidos juntos | *Pferd* (caballo) |
| r | gutural, al fondo de la garganta | *rot* (rojo) |
| -er final | casi una «a» breve | *Lehrer* (profesor) |
| -ig final | «ij» suave | *zwanzig* (veinte) |

Al **final de palabra**, b, d y g suenan como p, t y k: *Tag* suena «tak»; *und* (y), «unt»; *gelb* (amarillo), «guelp».

## Acento

La mayoría de las palabras alemanas se acentúan en la **primera sílaba**: *AR-bei-ten* (trabajar), *WOH-nung* (vivienda).

Excepciones frecuentes:

- Los prefijos inseparables *be-, ge-, er-, ver-, zer-, ent-, emp-* no llevan acento: *be-SU-chen* (visitar), *ver-STE-hen* (entender).
- Las palabras extranjeras suelen acentuarse al final: *Stu-DENT*, *Uni-ver-si-TÄT*, *Mu-SIK*.
- Los verbos terminados en *-ieren*: *stu-DIE-ren*.

## Saludos y frases básicas

| Alemán | Español |
|---|---|
| Hallo! | ¡Hola! |
| Guten Morgen! | Buenos días (por la mañana) |
| Guten Tag! | Buenos días, buenas tardes |
| Guten Abend! | Buenas tardes, buenas noches (al llegar) |
| Gute Nacht! | Buenas noches (al despedirse) |
| Tschüss! | ¡Chau! |
| Auf Wiedersehen! | Adiós, hasta la vista |
| Bis später! Bis morgen! | Hasta luego. Hasta mañana |
| Danke (schön). | Gracias |
| Bitte. | Por favor; de nada |
| Entschuldigung. | Perdón, disculpe |
| Ja. Nein. | Sí. No |
| Wie geht's? | ¿Cómo estás? |
| Gut, danke. Und dir? | Bien, gracias. ¿Y vos? |
| Wie heißt du? | ¿Cómo te llamás? |
| Ich heiße Ana. | Me llamo Ana |
| Woher kommst du? | ¿De dónde sos? |
| Ich komme aus Argentinien. | Soy de Argentina |
| Ich spreche ein bisschen Deutsch. | Hablo un poco de alemán |
| Ich verstehe nicht. | No entiendo |
| Sprechen Sie Englisch? | ¿Habla usted inglés? |
| Wie bitte? | ¿Cómo dice? |

En el sur de Alemania y en Austria se saluda con *Grüß Gott* o *Servus*; en Suiza, con *Grüezi*.

## Tú y usted

| Forma | Uso |
|---|---|
| **du** | familia, amigos, niños, estudiantes entre sí |
| **Sie** | desconocidos adultos, trato profesional y formal |

*Sie* (usted, ustedes) se escribe **siempre con mayúscula** y se conjuga como la tercera persona del plural.

## Números

| | | | |
|---|---|---|---|
| 0 null | 1 eins | 2 zwei | 3 drei |
| 4 vier | 5 fünf | 6 sechs | 7 sieben |
| 8 acht | 9 neun | 10 zehn | 11 elf |
| 12 zwölf | 13 dreizehn | 16 sechzehn | 17 siebzehn |
| 20 zwanzig | 30 dreißig | 40 vierzig | 100 hundert |

Desde el 21, las unidades van **antes** que las decenas, unidas con *und*: 21 es *einundzwanzig* («uno y veinte»); 45, *fünfundvierzig*; 99, *neunundneunzig*. 1000 es *tausend*.
