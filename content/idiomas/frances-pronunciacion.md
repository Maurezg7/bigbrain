## Leer francés

La ortografía francesa parece caprichosa, pero es bastante **regular para leer**: cada combinación de letras suena casi siempre igual. Lo difícil es el camino inverso (escribir lo que se oye).

Tres ideas generales:

1. Muchas **letras finales no se pronuncian**.
2. Varias letras juntas forman **un solo sonido**.
3. El acento de intensidad cae siempre en la **última sílaba** pronunciada.

## Vocales

| Grafía | Sonido | Ejemplo |
|---|---|---|
| a, à, â | «a» | *la*, *là*, *pâte* |
| i, î, y | «i» | *lit*, *île*, *stylo* |
| ou | «u» española | *vous*, *jour* |
| u, û | «i» con los labios redondeados | *tu*, *rue*, *sûr* |
| é, er, ez (final) | «e» cerrada | *café*, *parler*, *nez* |
| è, ê, ai, ei | «e» abierta | *père*, *fête*, *maison*, *neige* |
| e (sin acento) | muy breve, o muda al final | *le*, *petit*, *table* |
| o, ô, au, eau | «o» | *mot*, *hôtel*, *chaud*, *eau* |
| eu, œu | «e» con los labios redondeados | *bleu*, *deux*, *sœur*, *heure* |
| oi | «ua» | *moi*, *trois*, *voir* |

> [!IMPORTANT]
> **«u» y «ou» son sonidos distintos** y cambian el significado: *tu* (tú) y *tout* (todo); *rue* (calle) y *roue* (rueda).
>
> Para la «u» francesa: decir «i» y, sin mover la lengua, redondear los labios como para «u».

### Vocales nasales

El aire sale también por la nariz y la **n** o **m** que sigue **no se pronuncia**.

| Grafía | Sonido aproximado | Ejemplo |
|---|---|---|
| an, am, en, em | «a» nasal, grave | *enfant*, *temps*, *chambre* |
| on, om | «o» nasal | *bon*, *nom*, *maison* |
| in, im, ain, ein, un | «e» nasal, abierta | *vin*, *pain*, *plein*, *un*, *simple* |
| ien | «ie» nasal | *bien*, *rien* |
| oin | «ue» nasal | *loin*, *point* |

> [!WARNING]
> Si después de la **n** o **m** viene una vocal, o la consonante está duplicada, la vocal **no** es nasal: *bon* (nasal), pero *bonne* («bon»); *un* (nasal), pero *une* («ün»).

## Consonantes

| Grafía | Sonido | Ejemplo |
|---|---|---|
| ch | «sh» | *chat*, *chose* |
| j; g ante e, i | «y» suave y sonora (como en «yo» rioplatense) | *je*, *jour*, *manger* |
| g ante a, o, u | «g» de «gato» | *gare* |
| gn | «ñ» | *montagne* |
| c ante e, i; ç | «s» | *ce*, *garçon* |
| c ante a, o, u; qu | «k» | *café*, *qui* |
| s entre vocales | «z» sonora | *maison*, *rose* |
| ss | «s» sorda | *poisson* |
| z | «z» sonora | *zéro* |
| v | labiodental, distinta de «b» | *vin* |
| r | gutural, en la garganta | *rue*, *Paris* |
| h | siempre muda | *homme*, *hôtel* |
| ph | «f» | *photo* |
| th | «t» | *thé* |
| ill, il (tras vocal) | «i» semiconsonante («y») | *fille*, *travail* |
| tion | «sion» | *nation* |

> [!NOTE]
> *Poisson* («puasón», pescado) y *poison* («puazón», veneno) se distinguen solo por la «s» sorda o sonora.

Excepciones a «ill»: *ville*, *mille* y *tranquille* se pronuncian con «l».

## Letras finales mudas

> [!IMPORTANT]
> Las consonantes finales en general **no se pronuncian**, salvo **c, r, f, l** (las de la palabra inglesa *CaReFuL*).

| Palabra | Se pronuncia |
|---|---|
| *petit*, *grand*, *trop* | «petí», «gran» (nasal), «tro» |
| *Paris*, *vous*, *temps* | «parí», «vu», «tan» (nasal) |
| *avec*, *sac* | «avek», «sak» |
| *jour*, *mer* | «yur», «mer» |
| *neuf*, *chef* | «nœf», «shef» |
| *il*, *sel* | «il», «sel» |

La **-r** del infinitivo en *-er* no suena: *parler* → «parlé».

La **e** final sin acento es muda, pero hace sonar la consonante anterior:

| Masculino | Femenino |
|---|---|
| *petit* → «petí» | *petite* → «petit» |
| *grand* → «gran» | *grande* → «grand» |
| *étudiant* → «etüdián» | *étudiante* → «etüdiant» |

Las terminaciones verbales **-ent** (ellos) y la **-s** del plural son mudas: *ils parlent* suena igual que *il parle*.

## Liaison

Una consonante final normalmente muda **se pronuncia** cuando la palabra siguiente empieza con vocal o h muda, y se une a ella.

| Escrito | Se pronuncia |
|---|---|
| *les amis* | «le-z-amí» |
| *vous avez* | «vu-z-avé» |
| *un ami* | «ɛ̃-n-amí» |
| *petit enfant* | «peti-t-anfán» |
| *deux heures* | «dœ-z-œr» |
| *ils ont* | «il-z-on» |

En la liaison, **s** y **x** suenan «z», y **d** suena «t».

> [!NOTE]
> *Ils ont* («il-z-on», ellos tienen) e *ils sont* («il-son», ellos son) se distinguen por ese sonido.

Es obligatoria entre el artículo y el sustantivo, entre el pronombre y el verbo, y después de *très*, *dans*, *chez*. No se hace después de *et*.

### Elisión

Las palabras cortas terminadas en vocal pierden esa vocal ante otra vocal y toman **apóstrofo**:

| Completo | Con elisión |
|---|---|
| le + ami | *l'ami* |
| je + ai | *j'ai* |
| ne + est | *n'est* |
| que + il | *qu'il* |
| de + eau | *d'eau* |
| si + il | *s'il* |

### Encadenamiento

Las palabras se enlazan en la pronunciación: el francés se dice por **grupos**, no palabra por palabra. *Il est arrivé avec une amie* suena como una sola cadena.

## Acentos gráficos

En francés los acentos **no marcan la sílaba tónica**: cambian el sonido de la vocal o distinguen palabras.

| Signo | Nombre | Efecto | Ejemplo |
|---|---|---|---|
| é | agudo | «e» cerrada | *été*, *café* |
| è, à, ù | grave | «e» abierta; distingue palabras | *mère*; *où* (dónde) / *ou* (o) |
| ê, â, î, ô, û | circunflejo | suele indicar una «s» desaparecida | *forêt* (forest), *hôpital* |
| ë, ï | diéresis | la vocal se pronuncia aparte | *Noël*, *naïf* |
| ç | cedilla | «c» con sonido «s» ante a, o, u | *français*, *leçon* |

Pares que solo se distinguen por el acento: *a* (tiene) / *à* (a); *la* (la) / *là* (allí); *ou* (o) / *où* (dónde); *du* (del) / *dû* (debido).

## Homófonos

Por tantas letras mudas, muchas palabras suenan igual:

| Suena | Se escribe |
|---|---|
| «ver» | *vert* (verde), *verre* (vaso), *vers* (hacia), *ver* (gusano) |
| «so» | *seau* (balde), *sot* (tonto), *saut* (salto), *sceau* (sello) |
| «mer» | *mer* (mar), *mère* (madre), *maire* (alcalde) |
| «se» | *ces*, *ses*, *c'est*, *s'est*, *sait* |
| «parlé» | *parler*, *parlé*, *parlez*, *parlais* (casi igual) |

El contexto resuelve la ambigüedad.

## Entonación y ritmo

- Todas las sílabas duran aproximadamente lo mismo.
- El acento cae en la **última sílaba** del grupo: *Je vais à la bibliothÈQUE*.
- En las preguntas sin inversión, la voz **sube** al final: *Tu viens ?*

## El alfabeto

| Letra | Nombre | Letra | Nombre |
|---|---|---|---|
| e | «ø» (como *eu*) | j | «yi» |
| g | «ye» | h | «ash» |
| i | «i» | y | «i grec» |
| u | «ü» | w | «dublevé» |
| q | «kü» | z | «zed» |

> [!WARNING]
> Cuidado al deletrear: la **e** se llama como el sonido de *eu*, la **i** se llama «i», y **g** y **j** tienen los nombres cruzados respecto de lo que uno esperaría («ye» y «yi»).

## Puntuación

En francés se deja un **espacio antes** de los signos dobles: `?`, `!`, `:`, `;`. Las comillas son « así ». No hay signos de apertura.

## Resumen para leer

| Si ves | Leé |
|---|---|
| ou | «u» |
| u | «ü» |
| oi | «ua» |
| au, eau | «o» |
| ai, ei, è, ê | «e» abierta |
| eu, œu | «ø» |
| vocal + n/m (sin vocal después) | nasal |
| ch | «sh» |
| gn | «ñ» |
| consonante final (salvo c, r, f, l) | muda |
| e final | muda |

> [!TIP]
> Aprender cada palabra nueva **oyéndola**, no solo leyéndola. La ortografía sola lleva a pronunciar todas las letras, que es el error más común del hispanohablante.
