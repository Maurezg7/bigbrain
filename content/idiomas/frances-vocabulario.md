## Saludos y cortesía

| Francés | Español |
|---|---|
| Bonjour | Buen día, hola |
| Bonsoir | Buenas tardes, buenas noches (al llegar) |
| Bonne nuit | Buenas noches (al ir a dormir) |
| Salut ! | ¡Hola! / ¡Chau! (informal) |
| Au revoir | Adiós |
| À bientôt / À demain | Hasta pronto / Hasta mañana |
| Comment allez-vous ? | ¿Cómo está usted? |
| Ça va ? — Ça va bien. | ¿Todo bien? — Todo bien. |
| S'il vous plaît / S'il te plaît | Por favor (formal / informal) |
| Merci (beaucoup) | (Muchas) gracias |
| De rien / Je vous en prie | De nada |
| Pardon / Excusez-moi | Perdón / Disculpe |
| Enchanté(e) | Encantado/a |

> [!IMPORTANT]
> **Tu** se usa con amigos, familia y pares; **vous**, con desconocidos, mayores y en situaciones formales. Ante la duda, *vous*.

```text
— Bonjour ! Je m'appelle Ana. Et vous ?
— Enchanté. Moi, c'est Pierre. Vous venez d'où ?
— Je viens d'Argentine. Je suis étudiante.
```

## Números

| | | | |
|---|---|---|---|
| 0 zéro | 1 un / une | 2 deux | 3 trois |
| 4 quatre | 5 cinq | 6 six | 7 sept |
| 8 huit | 9 neuf | 10 dix | 11 onze |
| 12 douze | 13 treize | 14 quatorze | 15 quinze |
| 16 seize | 17 dix-sept | 18 dix-huit | 19 dix-neuf |
| 20 vingt | 30 trente | 40 quarante | 50 cinquante |
| 60 soixante | 100 cent | 1000 mille | |

Del 70 al 99 se cuenta de forma particular:

| Número | Francés | Literalmente |
|---|---|---|
| 70 | soixante-dix | sesenta-diez |
| 71 | soixante et onze | sesenta y once |
| 75 | soixante-quinze | sesenta-quince |
| 80 | quatre-vingts | cuatro-veintes |
| 81 | quatre-vingt-un | cuatro-veinte-uno |
| 90 | quatre-vingt-dix | cuatro-veinte-diez |
| 99 | quatre-vingt-dix-neuf | cuatro-veinte-diecinueve |

En Bélgica y Suiza se dice *septante* (70) y *nonante* (90).

21, 31, 41... llevan **et**: *vingt et un*. Los demás, guion: *vingt-deux*.

```text

```

### Partitivos

Para cantidades no contables se usa **du, de la, de l', des**:

```text
Je mange du pain.          Como pan.
Je bois de l'eau.          Tomo agua.
Je ne bois pas de café.    No tomo café.
```

## Adjetivos comunes

| Francés | Español | Francés | Español |
|---|---|---|---|
| bon, bonne | bueno | mauvais | malo |
| grand | grande, alto | petit | chico |
| nouveau, nouvelle | nuevo | vieux, vieille | viejo |
| beau, belle | lindo | laid | feo |
| facile | fácil | difficile | difícil |

| cher, chère | caro | bon marché | barato |
| heureux | feliz | triste | triste |

La mayoría de los adjetivos van **después** del sustantivo (*une voiture rouge*); algunos cortos y frecuentes van antes: *bon, mauvais, grand, petit, beau, nouveau, vieux, jeune*.

## Falsos amigos

| Francés | Significa | La palabra española se dice |
|---|---|---|
| **attendre** | esperar | atender: *s'occuper de* |
| **entendre** | oír | entender: *comprendre* |
| **quitter** | dejar, irse de | quitar: *enlever* |
| **rester** | quedarse | restar: *soustraire* |
| **salir** | ensuciar | salir: *sortir* |
| **subir** | sufrir, padecer | subir: *monter* |
| **constipé** | estreñido | constipado: *enrhumé* |
| **embarrassé** | incómodo, molesto | embarazada: *enceinte* |
| **large** | ancho | largo: *long* |
| **le nombre** | el número | el nombre: *le prénom, le nom* |
| **la carte** | el mapa, la tarjeta, el menú | la carta: *la lettre* |
| **le timbre** | la estampilla | el timbre: *la sonnette* |
| **la table** | la mesa | la tabla: *la planche* |
| **le tapis** | la alfombra | el tapiz: *la tapisserie* |
| **le gâteau** | la torta | el gato: *le chat* |
| **sol** | suelo | sol: *soleil* |
| **le dos** | la espalda | dos: *deux* |
| **mais** | pero | más: *plus* |
| **débile** | tonto | débil: *faible* |
| **exprimer** | expresar | exprimir: *presser* |
| **discuter** | conversar | discutir (pelear): *se disputer* |

> [!WARNING]
> Dos errores clásicos: decir *je suis constipé* por «estoy resfriado» (significa «estoy estreñido»), y *je suis embarrassée* por «estoy embarazada» (significa «estoy incómoda»).

## Conectores

| Francés | Español |
|---|---|
| et, ou, mais | y, o, pero |
| parce que | porque |
| donc, alors | entonces, por lo tanto |
| aussi | también |
| très, beaucoup | muy, mucho |
| un peu | un poco |
| plus, moins | más, menos |
| ici, là, là-bas | acá, ahí, allá |
| avec, sans | con, sin |
| pour | para |
| chez | en casa de |
| peut-être | tal vez |
| d'abord, ensuite, enfin | primero, después, por último |

> [!TIP]
> Aprender cada sustantivo **con su artículo** (*le*, *la*): el género no siempre coincide con el español (*la voiture*, el auto; *le lait*, la leche; *la mer*, el mar).
