## Cuántas palabras hacen falta

| Palabras conocidas | Alcanza para |
|---|---|
| 1000 | conversaciones básicas |
| 3000 | entender la mayor parte del habla cotidiana |
| 5000 | leer textos generales con comodidad |
| 8000 a 10 000 | leer textos académicos sin diccionario |

Conviene empezar por las más **frecuentes**: unas pocas miles de palabras cubren la gran mayoría de cualquier texto.

## Cognados

Cerca de la mitad del vocabulario inglés viene del latín o del francés, así que un hispanohablante reconoce miles de palabras. Hay patrones regulares:

| Español | Inglés | Ejemplos |
|---|---|---|
| -ción | -tion | información → information, nación → nation |
| -dad | -ty | universidad → university, calidad → quality |
| -mente | -ly | normalmente → normally |
| -oso | -ous | famoso → famous, nervioso → nervous |
| -ico | -ic, -ical | económico → economic, típico → typical |
| -ar, -er, -ir | -ate | crear → create, calcular → calculate |
| -ista | -ist | artista → artist |
| -encia, -ancia | -ence, -ance | diferencia → difference, importancia → importance |
| -ble | -ble | posible → possible |

## Sufijos

El sufijo indica la **categoría** de la palabra, lo que ayuda a entender una oración aunque no se conozca el término.

| Forma | Sufijos | Ejemplos |
|---|---|---|
| Sustantivos | -tion, -ment, -ness, -ity, -er, -ist, -ship, -ance | development, happiness, teacher, friendship |
| Adjetivos | -ful, -less, -able, -ous, -ive, -al, -ic | useful, useless, reliable, active |
| Verbos | -ize, -ify, -en, -ate | organize, simplify, widen |
| Adverbios | -ly | quickly, carefully |

Una familia completa:

| Verbo | Sustantivo | Adjetivo | Adverbio |
|---|---|---|---|
| create | creation, creativity | creative | creatively |
| succeed | success | successful | successfully |
| analyse | analysis | analytical | analytically |
| rely | reliability | reliable | reliably |

## Colocaciones

Son palabras que «van juntas» por costumbre. Traducir literalmente da errores.

| Correcto | No se dice | Español |
|---|---|---|
| **make** a mistake | ~~do a mistake~~ | cometer un error |
| **make** a decision | ~~take~~ (en EE. UU.) | tomar una decisión |
| **do** homework | ~~make homework~~ | hacer la tarea |
| **do** research | ~~make research~~ | investigar |
| **take** a photo | ~~make a photo~~ | sacar una foto |
| **take** an exam | ~~make an exam~~ | rendir un examen |
| **pass** an exam | | aprobar un examen |
| **have** breakfast | ~~take breakfast~~ | desayunar |
| **heavy** rain | ~~strong rain~~ | lluvia fuerte |
| **strong** coffee | ~~heavy coffee~~ | café fuerte |
| **pay** attention | ~~put attention~~ | prestar atención |

**Make** se usa en general para crear o producir (*make a cake, make a plan, make money*); **do**, para actividades y tareas (*do exercise, do the shopping, do your best*).

El español «tener» muchas veces es *be*: *I **am** 20 years old. I **am** hungry. I **am** cold. You **are** right.*

## Pares que se confunden

| Par | Diferencia |
|---|---|
| say / tell | *say something*; *tell someone something* |
| speak / talk | *speak* es más formal y se usa con idiomas; *talk* es conversar |
| lend / borrow | *lend* es prestar; *borrow*, pedir prestado |
| remember / remind | *remember* es recordar uno; *remind*, hacerle acordar a otro |
| win / earn | *win* un partido o premio; *earn* dinero con trabajo |
| hear / listen | *hear* es oír; *listen to*, escuchar con atención |
| see / look / watch | ver; mirar; mirar algo que se mueve o dura |
| job / work | *job* es contable (un empleo); *work*, incontable |
| trip / travel | *trip* es un viaje concreto; *travel*, la actividad en general |
| affect / effect | verbo / sustantivo |
| rise / raise | subir solo (*prices rise*) / subir algo (*raise your hand*) |
| bring / take | traer hacia acá / llevar hacia allá |
| fun / funny | divertido / gracioso |
| bored / boring | aburrido (me siento) / aburrido (lo que aburre) |

El último par es un patrón general: **-ed** describe lo que alguien siente y **-ing**, lo que causa la sensación. *I'm **interested** in the class. The class is **interesting**.*

## Comparativos y superlativos

| Adjetivo | Comparativo | Superlativo |
|---|---|---|
| Corto (una sílaba): tall | taller than | the tallest |
| Termina en -y: easy | easier than | the easiest |
| Largo: expensive | more expensive than | the most expensive |
| good | better | the best |
| bad | worse | the worst |
| far | farther, further | the farthest, the furthest |

Igualdad: *as tall **as***. Inferioridad: *less expensive **than***. Proporción: ***The more** you practise, **the better** you get.*

## Cómo fijar el vocabulario

- Aprender **frases**, no palabras sueltas: *make a decision*, no solo *decision*.
- Repetición espaciada con tarjetas.
- Leer mucho sobre temas que interesan.
- Usar la palabra nueva en una oración propia el mismo día.
