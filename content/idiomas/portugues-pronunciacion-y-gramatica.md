## Dos normas

| | Portugués de Brasil | Portugués de Portugal |
|---|---|---|
| Vocales átonas | se pronuncian claras | se reducen mucho o desaparecen |
| «tu / você» | *você* es lo habitual | *tu* es lo habitual |
| Gerundio | *estou falando* | *estou a falar* |
| «d», «t» ante «i» | suenan «dʒ», «tʃ»: *dia* → «dʒía» | no cambian |

Esta lección sigue la norma de **Brasil**, la más usada en Sudamérica.

## Vocales

El español tiene 5 vocales; el portugués, 7 orales y 5 nasales.

### Abiertas y cerradas

| Letra | Cerrada | Abierta |
|---|---|---|
| e | *você*, *medo* (como la «e» española) | *café*, *ela* (más abierta) |
| o | *avô* (abuelo), *todo* | *avó* (abuela), *nova* |

> [!IMPORTANT]
> La diferencia cambia el significado: *avô* (abuelo) y *avó* (abuela).

El acento gráfico lo indica: el **agudo** (´) marca vocal abierta y el **circunflejo** (^), cerrada.

En sílaba átona final, la **«o» suena «u»** y la **«e» suena «i»**: *livro* → «lívru», *leite* → «léitʃi».

### Nasales

El aire sale también por la nariz. Se marcan con **tilde** (~) o con **m / n** al final de sílaba.

| Grafía | Ejemplo | Significado |
|---|---|---|
| ã | *irmã*, *manhã* | hermana, mañana |
| ão | *não*, *pão*, *coração* | no, pan, corazón |
| õe | *põe*, *limões* | pone, limones |
| ãe | *mãe*, *pães* | madre, panes |
| am, an | *campo*, *canto* | campo, canto |
| em, en | *bem*, *tempo* | bien, tiempo |
| im, om, um | *sim*, *bom*, *um* | sí, bueno, uno |

La «m» o «n» final no se pronuncia como consonante: solo nasaliza la vocal. *Bem* suena aproximadamente «beĩ».

## Consonantes

| Grafía | Sonido | Ejemplo |
|---|---|---|
| ch | «sh» | *chave* (llave) |
| x | «sh», «s», «ks» o «z», según la palabra | *xícara*, *próximo*, *táxi*, *exame* |
| j; g ante e, i | como la «j» francesa (una «y» suave y sonora) | *janela*, *gente* |
| lh | parecido a «ll» | *filho* (hijo) |
| nh | «ñ» | *vinho* (vino) |
| ç | «s» | *coração* |
| s entre vocales | «z» sonora | *casa* |
| ss | «s» sorda | *passo* |
| z | «z» sonora | *zero* |
| r inicial y rr | aspirada, como una «j» suave | *rio*, *carro* |
| r entre vocales | vibrante simple | *caro* |
| l final de sílaba | «u» | *Brasil* → «Brasiu» |
| d, t ante «i» | «dʒ», «tʃ» | *dia*, *tia*, *noite* |
| v | labiodental, distinta de la «b» | *vaca* |

> [!WARNING]
> En portugués **«b» y «v» son sonidos distintos**, igual que **«s» y «z»**. *Casa* («caza») y *caça* («casa», caza) se distinguen solo por eso.

## Artículos

| | Definido | Indefinido |
|---|---|---|
| Masculino singular | o | um |
| Femenino singular | a | uma |
| Masculino plural | os | uns |
| Femenino plural | as | umas |

Se usa artículo ante posesivos y, coloquialmente, ante nombres propios: *o meu livro*, *a Maria*.

## Género

Casi siempre coincide con el español, pero hay excepciones frecuentes:

| Portugués | Español |
|---|---|
| **a** viagem, **a** paisagem, **a** coragem | el viaje, el paisaje, el coraje |
| **a** árvore | el árbol |
| **a** ponte | el puente |
| **a** cor, **a** dor | el color, el dolor |
| **o** leite, **o** sal, **o** mel | la leche, la sal, la miel |
| **o** sangue | la sangre |
| **o** nariz | la nariz |
| **o** computador | la computadora |

Regla útil: las palabras en **-agem** son femeninas (en español, *-aje* es masculino).

## Plural

| Terminación | Plural | Ejemplo |
|---|---|---|
| vocal | + s | *casa → casas* |
| r, z, s (aguda) | + es | *flor → flores*, *mês → meses* |
| m | → ns | *homem → homens* |
| al, el, ol, ul | → ais, éis, óis, uis | *animal → animais*, *papel → papéis* |
| il (tónica) | → is | *fuzil → fuzis* |
| ão | → ões (lo más común) | *limão → limões* |
| | → ães | *pão → pães*, *cão → cães* |
| | → ãos | *mão → mãos*, *irmão → irmãos* |

## Pronombres personales

| Persona | Pronombre | Uso |
|---|---|---|
| yo | eu | |
| tú | você / tu | *você* lleva el verbo en tercera persona |
| él, ella | ele, ela | |
| nosotros | nós / a gente | *a gente* es coloquial y lleva el verbo en tercera del singular |
| ustedes | vocês | |
| ellos, ellas | eles, elas | |

Trato formal: *o senhor*, *a senhora*.

> [!NOTE]
> *A gente vai à praia* = «Vamos a la playa». No significa «la gente».

## Demostrativos

| | Cerca del que habla | Cerca del que escucha | Lejos |
|---|---|---|---|
| Masculino | este | esse | aquele |
| Femenino | esta | essa | aquela |
| Neutro | isto | isso | aquilo |

Se contraen con las preposiciones: *neste* (em + este), *desse* (de + esse), *naquele* (em + aquele), *àquele* (a + aquele).

## Posesivos

| Poseedor | Masculino | Femenino |
|---|---|---|
| eu | meu(s) | minha(s) |
| tu | teu(s) | tua(s) |
| você, ele, ela | seu(s) | sua(s) |
| nós | nosso(s) | nossa(s) |

Como *seu* es ambiguo, para la tercera persona se prefiere *dele*, *dela*, *deles*, *delas*: *o carro dele* (el auto de él).

## Contracciones

| Preposición | + o, a | + um, uma | + ele, ela |
|---|---|---|---|
| de | do, da | dum, duma | dele, dela |
| em | no, na | num, numa | nele, nela |
| a | ao, à | — | — |
| por | pelo, pela | — | — |

> [!WARNING]
> *No* significa «en el», no es la negación (que es *não*). *Estou no Brasil* = «Estoy en Brasil».

## Negación y preguntas

```text
Eu não falo inglês.            No hablo inglés.
Você fala português?           ¿Hablás portugués?
Onde você mora?                ¿Dónde vivís?
```

La pregunta solo cambia la entonación; no hay signo de apertura.

| Portugués | Español |
|---|---|
| o que | qué |
| quem | quién |
| onde | dónde |
| quando | cuándo |
| como | cómo |
| por que | por qué |
| quanto | cuánto |
| qual | cuál |

Para responder que sí, se suele repetir el verbo: *— Você fala português? — Falo.*

## Diferencias de ortografía

| Español | Portugués | Ejemplo |
|---|---|---|
| ll | ch | lluvia → *chuva*, llamar → *chamar* |
| ñ | nh | España → *Espanha* |
| -ción | -ção | nación → *nação* |
| -dad | -dade | ciudad → *cidade* |
| -ble | -vel | posible → *possível* |
| h inicial | f | hacer → *fazer*, hijo → *filho* |
| ue, ie | o, e | puerta → *porta*, tierra → *terra* |
| -an, -ón | -ão | corazón → *coração*, pan → *pão* |

> [!TIP]
> Entender portugués escrito es fácil para un hispanohablante; lo difícil es el oído. Escuchar mucho desde el principio, prestando atención a las nasales y a las vocales átonas.
