## Saludos y cortesía

| Portugués | Español |
|---|---|
| Oi! / Olá! | ¡Hola! |
| Bom dia | Buen día |
| Boa tarde | Buenas tardes |
| Boa noite | Buenas noches |
| Tudo bem? — Tudo bem. | ¿Todo bien? — Todo bien. |
| Como vai? | ¿Cómo te va? |
| Tchau! / Até logo! | ¡Chau! / ¡Hasta luego! |
| Até amanhã | Hasta mañana |
| Por favor | Por favor |
| Obrigado / Obrigada | Gracias (lo dice un hombre / una mujer) |
| De nada | De nada |
| Desculpe / Com licença | Perdón / Permiso |
| Prazer | Mucho gusto |

> [!IMPORTANT]
> «Gracias» concuerda con **quien habla**: un hombre dice *obrigado* y una mujer, *obrigada*.

```text
— Oi, tudo bem? Meu nome é Ana. Qual é o seu nome?
— Prazer, Ana. Eu sou o Pedro. De onde você é?
— Sou da Argentina. E você?
— Sou do Brasil, de São Paulo.
```

## Números

| | | | |
|---|---|---|---|
| 0 zero | 1 um / uma | 2 dois / duas | 3 três |
| 4 quatro | 5 cinco | 6 seis | 7 sete |
| 8 oito | 9 nove | 10 dez | 11 onze |
| 12 doze | 13 treze | 14 catorze | 15 quinze |
| 16 dezesseis | 17 dezessete | 18 dezoito | 19 dezenove |
| 20 vinte | 30 trinta | 40 quarenta | 50 cinquenta |
| 60 sessenta | 70 setenta | 80 oitenta | 90 noventa |
| 100 cem | 200 duzentos | 500 quinhentos | 1000 mil |

- **1** y **2** tienen femenino: *uma casa*, *duas casas*.
- *Cem* es 100 exacto; con más, *cento*: *cento e um* (101).
- Se une con **e**: *vinte e cinco* (25), *duzentos e trinta e quatro* (234).
- Por teléfono, el 6 suele decirse *meia* (de «media docena»).

## Falsos amigos

Palabras que se parecen al español pero significan otra cosa.

| Portugués | Significa | La palabra española se dice |
|---|---|---|
| **esquisito** | raro, extraño | exquisito: *delicioso* |
| **exquisito** | (no se usa) | |
| **embaraçada** | avergonzada, confundida | embarazada: *grávida* |
| **polvo** | pulpo | polvo: *pó, poeira* |
| **vaso** | maceta, florero; inodoro | vaso: *copo* |
| **copo** | vaso | copo (de nieve): *floco* |
| **borracha** | goma (de borrar) | borracha: *bêbada* |
| **largo** | ancho | largo: *comprido, longo* |
| **rato** | ratón | rato: *momento* |
| **cena** | escena | cena: *jantar* |
| **oficina** | taller | oficina: *escritório* |
| **escritório** | oficina | escritorio: *escrivaninha, mesa* |
| **apelido** | apodo | apellido: *sobrenome* |
| **sobrenome** | apellido | sobrenombre: *apelido* |
| **propina** | soborno | propina: *gorjeta* |
| **salsa** | perejil | salsa: *molho* |
| **pasta** | carpeta | pasta (comida): *massa, macarrão* |
| **ano** | año | |
| **pelado** | desnudo | pelado: *careca* |
| **ruivo** | pelirrojo | rubio: *loiro* |
| **todavia** | sin embargo | todavía: *ainda* |
| **logo** | pronto, enseguida | luego: *depois* |
| **acordar** | despertarse | acordarse: *lembrar-se* |
| **pegar** | agarrar, tomar | pegar: *bater; colar* |
| **tirar** | sacar | tirar: *jogar; puxar* |
| **contestar** | impugnar, cuestionar | contestar: *responder* |
| **aceitar** | aceptar | aceitar (untar con aceite): *untar* |
| **azeite** | aceite de oliva | aceite (en general): *óleo* |
| **cadeira** | silla | cadera: *quadril* |
| **cachorro** | perro | cachorro: *filhote* |
| **criança** | niño | crianza: *criação* |
| **sobremesa** | postre | sobremesa: (no tiene equivalente exacto) |
| **talher** | cubierto | taller: *oficina* |
| **cola** | pegamento | cola (fila): *fila* |

> [!WARNING]
> Algunos errores clásicos del «portuñol»: decir *estou embaraçada* queriendo decir «estoy embarazada», pedir *um vaso de água* (un florero de agua), o decir que una comida está *esquisita* (rara) para elogiarla.

## Expresiones cotidianas

| Portugués | Significado |
|---|---|
| Legal! | ¡Qué bueno! ¡Genial! |
| Beleza? | ¿Todo bien? |
| Valeu! | ¡Gracias! (informal) |
| Tá bom / Tá | Está bien, de acuerdo |
| Com certeza | Seguro, por supuesto |
| Claro | Claro |
| Né? (não é?) | ¿No?, ¿verdad? |
| Nossa! | ¡Uy!, ¡Guau! |
| Que saudade! | ¡Cuánto extraño...! |
| Fique à vontade | Ponete cómodo |
| Não faz mal | No importa |
| Não entendi | No entendí |
| Pode repetir, por favor? | ¿Podés repetir, por favor? |
| Como se diz ... em português? | ¿Cómo se dice ... en portugués? |
| Fala mais devagar, por favor | Hablá más despacio, por favor |

**Saudade** es la nostalgia por alguien o algo ausente: *Estou com saudade de você* («Te extraño»).

### Estados con «estar com»

Muchas sensaciones se expresan con *estar com* + sustantivo:

| Portugués | Español |
|---|---|
| estou com fome | tengo hambre |
| estou com sede | tengo sed |
| estou com sono | tengo sueño |
| estou com frio / calor | tengo frío / calor |
| estou com pressa | estoy apurado |
| estou com medo | tengo miedo |
| estou com dor de cabeça | me duele la cabeza |
