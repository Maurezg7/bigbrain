## Número de oxidación

Es la carga que tendría un átomo si todos sus enlaces fueran iónicos. Es la base para escribir y nombrar fórmulas.

| Regla | Ejemplo |
|---|---|
| Un elemento libre tiene 0 | Fe, O₂, Cl₂ |
| En un ion monoatómico es igual a la carga | Na⁺ → +1 |
| El oxígeno casi siempre es −2 (en peróxidos, −1) | H₂O; H₂O₂ |
| El hidrógeno es +1 (en hidruros metálicos, −1) | HCl; NaH |
| Los metales alcalinos son +1 y los alcalinotérreos +2 | K⁺, Ca²⁺ |
| El flúor siempre es −1 | HF |
| La suma en un compuesto neutro es 0; en un ion, su carga | SO₄²⁻ → −2 |

> [!NOTE]
> Número de oxidación del azufre en H₂SO₄: $2(+1) + x + 4(-2) = 0 \Rightarrow x = +6$.
>
> Del manganeso en MnO₄⁻: $x + 4(-2) = -1 \Rightarrow x = +7$.

### Números de oxidación frecuentes

| Elemento | Valores |
|---|---|
| Na, K, Ag | +1 |
| Mg, Ca, Zn | +2 |
| Al | +3 |
| Fe | +2, +3 |
| Cu | +1, +2 |
| Pb, Sn | +2, +4 |
| C | +2, +4 |
| N | +3, +5 |
| S | +4, +6 (y −2) |
| Cl, Br, I | +1, +3, +5, +7 (y −1) |

## Formular

El elemento más electropositivo se escribe a la izquierda. Los números de oxidación se **cruzan** como subíndices y se simplifica si se puede.

> [!NOTE]
> Aluminio (+3) y oxígeno (−2): Al₂O₃. Calcio (+2) y oxígeno (−2): Ca₂O₂ → CaO.

## Tres sistemas de nombres

| Sistema | Cómo indica la proporción | Fe₂O₃ |
|---|---|---|
| **Tradicional** | sufijos **-oso** (menor) e **-ico** (mayor) | óxido férrico |
| **Stock** | número de oxidación en romanos | óxido de hierro(III) |
| **Sistemática** | prefijos mono-, di-, tri-, tetra-... | trióxido de dihierro |

Si el elemento tiene un solo número de oxidación, no hace falta aclararlo: óxido de sodio.

Con cuatro números de oxidación, la tradicional usa: **hipo-...-oso**, **-oso**, **-ico**, **per-...-ico**.

## Compuestos binarios

### Óxidos

| Tipo | Formado por | Ejemplo | Stock | Tradicional |
|---|---|---|---|---|
| Óxido básico | metal + oxígeno | FeO | óxido de hierro(II) | óxido ferroso |
| | | CuO | óxido de cobre(II) | óxido cúprico |
| Óxido ácido | no metal + oxígeno | CO₂ | óxido de carbono(IV) | anhídrido carbónico |
| | | SO₃ | óxido de azufre(VI) | anhídrido sulfúrico |

Para los óxidos ácidos es muy común la sistemática: dióxido de carbono, trióxido de azufre, monóxido de carbono.

### Hidruros y hidrácidos

| Tipo | Ejemplo | Nombre |
|---|---|---|
| Hidruro metálico | NaH | hidruro de sodio |
| Hidruro no metálico | NH₃, CH₄ | amoníaco, metano |
| Hidrácido (en agua) | HCl | ácido clorhídrico (cloruro de hidrógeno como gas) |
| | H₂S | ácido sulfhídrico |

### Sales binarias

Metal + no metal. El no metal lleva la terminación **-uro**.

| Fórmula | Stock | Tradicional |
|---|---|---|
| NaCl | cloruro de sodio | cloruro de sodio |
| FeCl₃ | cloruro de hierro(III) | cloruro férrico |
| CuS | sulfuro de cobre(II) | sulfuro cúprico |
| CaF₂ | fluoruro de calcio | fluoruro de calcio |

## Compuestos ternarios

### Hidróxidos

Óxido básico + agua. Contienen el ion hidróxido, OH⁻. Fórmula: M(OH)ₙ.

| Fórmula | Nombre |
|---|---|
| NaOH | hidróxido de sodio |
| Ca(OH)₂ | hidróxido de calcio |
| Fe(OH)₃ | hidróxido de hierro(III) o férrico |

### Oxoácidos

Óxido ácido + agua. Fórmula general: HₐXOᵦ.

| Fórmula | N.º de oxidación | Nombre tradicional |
|---|---|---|
| HClO | +1 | ácido hipocloroso |
| HClO₂ | +3 | ácido cloroso |
| HClO₃ | +5 | ácido clórico |
| HClO₄ | +7 | ácido perclórico |
| H₂SO₃ | +4 | ácido sulfuroso |
| H₂SO₄ | +6 | ácido sulfúrico |
| HNO₂ | +3 | ácido nitroso |
| HNO₃ | +5 | ácido nítrico |
| H₂CO₃ | +4 | ácido carbónico |
| H₃PO₄ | +5 | ácido fosfórico |

### Oxosales

Resultan de reemplazar los hidrógenos de un oxoácido por un metal. El nombre del anión cambia la terminación del ácido:

> [!IMPORTANT]
> | Ácido | Anión |
> |---|---|
> | **-oso** | **-ito** |
> | **-ico** | **-ato** |
> | **-hídrico** | **-uro** |

| Anión | Nombre | Sal | Nombre |
|---|---|---|---|
| SO₄²⁻ | sulfato | CuSO₄ | sulfato de cobre(II) |
| SO₃²⁻ | sulfito | Na₂SO₃ | sulfito de sodio |
| NO₃⁻ | nitrato | KNO₃ | nitrato de potasio |
| NO₂⁻ | nitrito | NaNO₂ | nitrito de sodio |
| CO₃²⁻ | carbonato | CaCO₃ | carbonato de calcio |
| PO₄³⁻ | fosfato | Ca₃(PO₄)₂ | fosfato de calcio |
| ClO⁻ | hipoclorito | NaClO | hipoclorito de sodio |
| MnO₄⁻ | permanganato | KMnO₄ | permanganato de potasio |

> [!NOTE]
> Formular el sulfato de aluminio: Al³⁺ y SO₄²⁻. Cruzando las cargas: Al₂(SO₄)₃.

### Sales ácidas

Conservan algún hidrógeno del ácido. Se nombran con **hidrógeno-** (o el prefijo tradicional **bi-**).

| Fórmula | Nombre |
|---|---|
| NaHCO₃ | hidrogenocarbonato de sodio (bicarbonato de sodio) |
| KHSO₄ | hidrogenosulfato de potasio |
| NaH₂PO₄ | dihidrogenofosfato de sodio |

## Hidratos

Sales que incorporan moléculas de agua en su cristal: CuSO₄·5H₂O es el sulfato de cobre(II) pentahidratado.

> [!WARNING]
> Cuando un ion poliatómico aparece más de una vez, va entre paréntesis: Ca(OH)₂ tiene dos grupos hidróxido; CaOH₂ sería otra cosa.

> [!TIP]
> Para nombrar una sal, identificar primero el anión y deducir de su carga el número de oxidación del metal.
